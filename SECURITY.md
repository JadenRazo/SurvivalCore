# Security Policy

## Support status

SurvivalCore is archived and has no supported versions or security release commitment. It should not be used as a production server distribution.

## Reporting

If a finding concerns code original to this repository, use GitHub's private vulnerability reporting feature when available. Otherwise, contact `contact@jadenrazo.dev` with affected files, reproduction details, and potential impact.

Report vulnerabilities in Paper, Minecraft, Gradle, paperweight, or another dependency to that upstream project. Do not include credentials, private server addresses, player information, exploit payloads, or world data in a public issue.
